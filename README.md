# RalkyTech Landing Page

Landing page institucional da **RalkyTech**, desenvolvida para apresentar serviços, soluções digitais, equipe e projetos com uma identidade visual moderna e responsiva.

## Visão geral

Este projeto representa a presença digital da RalkyTech, com foco em:

- desenvolvimento web
- prototipação
- interfaces modernas
- experiência do usuário
- apresentação institucional da equipe
- destaque para projeto/case

A interface foi atualizada com uma proposta mais moderna e tecnológica, mantendo a paleta original da marca.

## Melhorias aplicadas

- reescrita do conteúdo da landing page com linguagem mais moderna e profissional
- correção de contraste em títulos e headings
- refatoração do CSS para arquitetura **mobile-first**
- melhoria da responsividade entre mobile, tablet e desktop
- refinamento visual de seções, cards e elementos de destaque
- ajuste da apresentação institucional e do footer

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
